# Verity user guide

This is the guide for the people who use Verity day to day: the compliance lead
preparing for an audit, the control owner who has been asked for evidence, the
security officer triaging a finding, the manager who signs off a policy.

It is written as walkthroughs. Every section answers "how do I actually do this",
step by step, with a picture of the screen you will be looking at.

## How to read a walkthrough

Steps are numbered and each one names the thing you click by the words printed on
it. Where a choice has a consequence that is hard to undo, there is a note like
this:

> **Before you click.** Declining a vendor request keeps the reason forever and
> cannot be reversed. Raise a new request instead of editing a declined one.

## Two notes on this release

**The Dashboard screen is a preview.** It shows the shape of the executive view,
with illustrative figures rather than your workspace's own. Every live number lives
on the module you are looking at: Get Started tracks your real setup progress,
Frameworks has a compliance dashboard, and Risks, Vendors, Assets, Vulnerabilities
and Tasks each have an Overview tab that reads from your data.

**Screens marked "Soon" are not built yet.** They appear so you can see where the
product is going. Nothing behind a Soon badge holds real data.
