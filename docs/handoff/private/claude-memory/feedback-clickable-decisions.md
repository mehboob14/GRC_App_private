When owner decisions are pending, ask them with the clickable question tool, not as prose: a few questions per round,
each with a recommended option first, multi-select where several can be true (confirmations, "which to build next"),
and audit or assessment topics in a separate round from the product ones.

**Why:** on 2026-11-23 the owner asked "ask me pending things where I can click, even on multiples, open items, and
separate audit thing", then answered fourteen open decisions in four rounds.

**How to apply:** before a long build stops on open decisions, batch them into rounds this way; record the answers in
the plan's decision table and local-context DECISIONS.md. Related: [[verity-guided-onboarding-plan]].
