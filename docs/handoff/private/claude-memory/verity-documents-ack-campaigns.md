**Flow the user asked for (all working):** a document OWNER starts a campaign against ANY document (no publish gate) → picks reviewers + approvers by any mix of **users / roles / groups** (searchable multi-select) → recipients see a **pending-acknowledgement icon beside their profile top-right** (count badge) → click → **dedicated campaign page** to read the doc + comment + press **Acknowledge** (status → acknowledged-by-whom + their comment) → owner sees **who acknowledged / who's pending** + all comments, can **comment and tag anybody**, and **Close** the campaign.
