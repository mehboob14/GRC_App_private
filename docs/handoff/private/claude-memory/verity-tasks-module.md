2. **populate_existing bug (would have crashed every mutating endpoint):** `updated_at` uses server-side `onupdate=func.now()`, so a flushed UPDATE expires it; re-rendering through `_load`→`_to_row` then lazy-loads an expired column, illegal in async SQLAlchemy (MissingGreenlet).
